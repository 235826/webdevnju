# 011：移动端适配

> 状态：草案
>
> 关联事项：Web 开发技术课程大作业

## 目标

用户可以在桌面端和移动端完成赛事浏览、详情查看、预测、收藏、评论和基础管理操作。

## 用户故事

作为移动端用户，我希望页面在手机屏幕上仍然可读、可操作，以便随时查看比赛并参与互动。

## 范围

- 赛事列表和详情的移动端适配。
- 球队详情的移动端适配。
- 预测、收藏和评论操作的移动端适配。
- 积分榜和淘汰赛图的移动端可读展示。
- 管理员基础操作页面的移动端基本可用。

## 非目标

- 原生 App。
- 离线访问。
- 针对所有异常尺寸设备做像素级一致。

## 业务规则

- **BR-01**：关键页面在移动端不得出现主要内容横向溢出。
- **BR-02**：主要交互控件在移动端应可点击、可聚焦且文字不溢出。
- **BR-03**：异步数据页面应在移动端保留加载、成功、空结果和错误状态。
- **BR-04**：积分榜和淘汰赛图在小屏上必须能完整访问信息，可通过滚动或分段展示实现。

## Contract 影响

- 结论：无。
- 理由或影响摘要：本 Spec 只约束前端呈现和交互，不改变 HTTP 请求或响应。
- OpenAPI operation：无。
- 迁移 / 废弃安排：不适用。

## 验收标准

- **AC-01**：给定移动端视口，当用户打开赛事列表、比赛详情和球队详情时，则主要内容可读且没有页面级横向溢出。
- **AC-02**：给定移动端视口，当用户进行登录、预测、收藏和评论操作时，则控件可点击、文字不溢出、错误提示可见。
- **AC-03**：给定移动端视口和空数据，当用户打开赛事、球队、评论或收藏列表时，则页面显示明确空状态。
- **AC-04**：给定移动端视口和请求失败，当用户访问核心页面时，则页面显示不包含内部诊断信息的错误状态。
- **AC-05**：给定移动端视口，当用户查看积分榜或淘汰赛图时，则所有球队、比分和轮次信息均可访问。
