# 001：用户登录与身份识别

> 状态：草案
>
> 关联事项：Web 开发技术课程大作业

## 目标

用户可以真实注册并登录，系统可以区分普通用户和管理员。

## 用户故事

作为访客，我希望注册并登录平台，以便使用预测、收藏和评论等个人化功能。

## 范围

- 普通用户注册。
- 用户登录、登出和当前用户识别。
- 普通用户与管理员角色识别。
- 通过数据库种子数据提供管理员账号。
- 受保护接口拒绝未认证访问。

## 非目标

- 第三方 OAuth 登录。
- 找回密码、邮箱验证或短信验证。
- 用户个人资料复杂编辑。
- 前端以外渠道创建管理员。

## 业务规则

- **BR-01**：普通用户可以通过注册创建账号。
- **BR-02**：管理员账号由数据库种子数据提供，不通过公开注册产生。
- **BR-03**：未认证用户不得访问需要身份的预测、收藏、评论写入和管理接口。
- **BR-04**：普通用户不得执行管理员专属操作。
- **BR-05**：认证失败时返回安全错误，不暴露密码、散列值、数据库路径或内部堆栈。

## Contract 影响

- 结论：新增。
- 理由或影响摘要：需要新增认证、注册、当前用户和登出相关 HTTP 行为，并为受保护接口定义认证错误。
- OpenAPI operation：`POST /api/auth/register`、`POST /api/auth/login`、`POST /api/auth/logout`、`GET /api/auth/me`。
- 迁移 / 废弃安排：不适用。

## 验收标准

- **AC-01**：给定未注册访客，当提交合法注册信息时，则系统创建普通用户并返回可登录状态或可用于登录的成功响应。
- **AC-02**：给定已注册用户，当提交正确凭据登录时，则系统返回成功响应，后续当前用户查询能识别该用户。
- **AC-03**：给定未认证请求，当访问受保护接口时，则响应为未认证错误且不执行业务写入。
- **AC-04**：给定普通用户，当访问管理员接口时，则响应为无权限错误且不执行业务写入。
- **AC-05**：给定数据库初始化完成，当使用种子管理员凭据登录时，则当前用户显示管理员角色。
- **AC-06**：给定认证失败，当客户端收到错误响应时，则响应不包含密码、散列值、数据库路径或内部堆栈。
